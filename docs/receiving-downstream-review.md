# Receiving downstream impact review

Scope: both receiving interfaces and the existing receipt/import → warehouse stock → consolidation → container assignment → confirmation/export/tracking paths. The recorded demo is paused. No demo shipment was finalized or pushed during this review.

## Data and calculation contract

Procurement declarations and original order pricing stay in `order_items`. Operational cargo uses active warehouse receipts. CBM, weight, and cartons sum all non-voided receipts, including partial deliveries. Item quantities use receipt actuals where supplied. Missing actuals fall back to declarations; zero actuals remain zero. Order-level measurements are not invented or allocated across items with missing measurements.

`CargoMetricsService` supplies the same operational totals to order/buyer summaries, draft totals, container usage/details, assignment previews, capacity validation, and container exports/tracking payloads. Shipping item projections are copies; they do not rewrite procurement or financial postings. Original custom amounts remain intact when quantity has not changed; complete receipt amounts and current sell pricing are used in shipping projections where available.

## Validation and limits

- `php tests/cargo_downstream_regression_test.php`: rollback-only calculation/service checks and 20 endpoint probes, including generated XLSX/CSV; confirms fixture row counts and notification configuration return to their baselines. Notifications are dashboard-only inside the uncommitted test transaction; no external delivery is sent.
- `node tests/receiving_ui_regression_test.cjs`: refresh, filtering races, pagination, cumulative evidence warnings, import refresh, shared API delegation, action visibility, selection persistence/compatibility and stale photo completion.
- Existing consolidation interaction, tracking UI, page capability, receiving RBAC, warehouse filter and live warehouse endpoint checks pass.
- PHP/JavaScript syntax and `git diff --check` pass. The persistent headed Cherry browser remains open with no pending test interception.
- Browser fixture checks are explicitly QA, not claimed as real receiving/assignment. Actual demo container `SG-BEY-260918-20GP` retains 5 orders, 55 cartons, 3,084 pieces, 4.27 CBM, 744 kg and To Go status.
- External carrier delivery, finalization of the demo shipment, and production concurrent-load testing were not executed. This review does not claim the entire CLMS application is bug-free outside the affected workflow.
